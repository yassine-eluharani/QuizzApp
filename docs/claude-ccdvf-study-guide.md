## Suggested study sequence

1. Read the exam guide, the detailed objectives, and its official sample questions.
2. Build a small Messages API application with error handling, streaming, and a tool-use loop. Study [the Claude API documentation](https://platform.claude.com/docs/en/home) and [tool use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview).
3. Practice configuring and operating [Claude Code](https://code.claude.com/docs/en/overview), including instructions, settings, skills, hooks, and subagents.
4. Study [prompt engineering](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview), context management, output validation, and an evaluation set.
5. Explore model, token, latency and cost tradeoffs, including [prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) and [batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing).
6. Build or connect an [MCP server](https://modelcontextprotocol.io/docs/getting-started/intro) and practice least-privilege permissions, handling untrusted inputs, and protecting credentials.
